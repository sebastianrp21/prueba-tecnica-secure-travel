# Secure Travel Cartagena - Plugin de Reservas

Prueba técnica para el rol de Desarrollador Junior WordPress.

## Descripción
Este plugin permite gestionar habitaciones, clientes y reservas desde el panel de administración. Incluye una simulación de pasarela de pagos.

## Funcionalidades
* **Gestión de Habitaciones:** Creación de tipos (Sencilla, Doble, Familiar) y estados.
* **Sistema de Reservas:** Cálculo automático de tarifas por noche.
* **Simulación de Pagos:** Clase PHP que simula transacciones bancarias (Aprobado/Rechazado) de forma aleatoria.
* **Reportes:** Widget en el Escritorio con ocupación en tiempo real.

## Instalación
1. Descargar el archivo PHP.
2. Subir a la carpeta `wp-content/plugins/secure-travel-reservas/`.
3. Activar desde el panel de plugins.
